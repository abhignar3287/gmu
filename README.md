# GMU NEXUS

**Connect. Discover. Collaborate.**

One University. One Network. Every Opportunity.

GMU Nexus is an AI-powered university-wide student ecosystem that connects students, branches, departments, organizers, events, hackathons, scholarships, internships, competitions, workshops, projects and announcements — all in one intelligent platform.

## The Problem

Students, opportunities, events and talented people already exist within the university, but information is scattered across branches, departments, groups, notices and different platforms. GMU Nexus brings the entire university ecosystem into one platform.

## Key Features

### AI-Powered Intelligence Layer
- **AI Q&A** — Ask questions about GMU in natural language
- **Smart Information Search** — Search across students, events, opportunities, scholarships and posts
- **Personalized Student Assistance** — AI recommendations based on skills, interests and branch
- **AI Skill Matching** — Connects students with complementary skills
- **AI Team Builder** — Describe what you need, get a recommended team with compatibility score
- **Opportunity & Event Recommendations** — Match-scored to your profile
- **AI Information Categorization** — Auto-tags posts by category, branch and topic

### Core Platform
- **Home Dashboard** — Personalized greeting, AI quick assistant, recommendations, today's events
- **Discover** — Universal search across the entire ecosystem
- **Connect** — Find students by skill, branch or interest; send connection requests
- **Opportunity Hunter** — Internships, scholarships, hackathons, competitions, research and more
- **Events Hub** — All GMU events with working registration and save/bookmark
- **Branch Connect** — Per-branch ecosystem with inter-branch collaboration
- **Student Posts** — Create posts with AI auto-categorization and verified information badges
- **Profile** — Editable skills, interests, projects; changes affect AI recommendations
- **Notifications** — Real-time notification center
- **Organizer Mode** — Create events and announcements with Branch Verified status
- **Admin Dashboard** — University-wide statistics and charts

### Verified Information System
- **Official GMU** — University-published content
- **Branch Verified** — Organizer-published content
- **Student Shared** — Student-generated content

## 3-Minute Demo Flow
1. **Home** — See personalized dashboard with AI assistant
2. **AI** — Ask "What opportunities are available for me?"
3. **Team Builder** — Ask "I need a React developer and UI/UX designer for my AI hackathon team"
4. **Events** — Browse and register for events
5. **Branch Connect** — Explore inter-branch collaboration
6. **Opportunity Hunter** — See match-scored opportunities
7. **Back to dashboard** — Connect. Discover. Collaborate.
